# Спортивная мафия онлайн: демо

Правила игры, сервер комнат, интерфейс в браузере и голос через LiveKit.
Правила взяты по регламенту ФСМ (редакция 23.01.2023) плюс решения, которые мы утвердили в документе с правилами.

## Как запустить

Нужен Node.js 22.18 или новее: он запускает TypeScript сам.

```bash
npm install
npm start         # собирает интерфейс и запускает сервер на http://localhost:8080
npm test          # тесты: правила, целые партии по сети, голос
npm run typecheck # проверка типов
```

Быстрая проверка одному: все таймеры в 5 раз короче.

```bash
# macOS и Linux
TIMER_SCALE=0.2 npm start
# Windows (PowerShell)
$env:TIMER_SCALE=0.2; npm start
```

## Как сыграть пробную партию

Сыграть самому:

1. Откройте http://localhost:8080, введите ник и нажмите «Создать и играть самому».
2. Нажмите «Добрать стол ботами», затем «Начать раздачу карт».
3. Дождитесь своей очереди и возьмите карту из колоды. Дальше играйте: ваша минута, выставление нажатием на номер за столом, голосование, ночные действия.
4. После партии нажмите «Сыграть ещё раз».

Посмотреть игру глазами ведущего: «Создать и вести игру», а во второй вкладке в режиме инкогнито войдите игроком по ссылке из лобби.

Другие люди в той же Wi-Fi сети могут зайти по адресу вашего компьютера, например http://192.168.1.5:8080.
Чтобы играть через интернет, сервер нужно разместить на хостинге.

## Что где лежит

```
engine/          правила игры, без сети
  types.ts       роли, фазы, действия, длительности
  game.ts        игровой движок: день, голосование, ночь, фолы, победа
  view.ts        что видит каждый: ведущий, игрок, выбывший, наблюдатель
server/          сервер комнат
  protocol.ts    сообщения между браузером и сервером
  room.ts        комната: лобби, участники, таймеры, рассылка
  bots.ts        боты для проверки без 10 живых людей
  voice.ts       голос: пропуски LiveKit и права на микрофон
  index.ts       HTTP + WebSocket, список комнат, сохранение партий
client/          интерфейс (чистый TypeScript, без фреймворка)
  build.ts       сборка: client/src → client/dist
  src/main.ts    связь с сервером, отрисовка, нажатия
  src/voice.ts   голос в браузере: подключение, микрофон по правилам
  src/views/     экраны: вход и лобби, стол игрока, панель ведущего
  src/styles.css оформление по макетам
test/
  engine.test.ts правила по пунктам
  server.test.ts целые партии через настоящий сервер
data/games.jsonl итоги сыгранных партий (появится после первой игры)
```

## Главный принцип

Сервер знает всё, браузер получает только своё. Перед отправкой состояние проходит через `viewFor()`:

| Кто | Что видит |
| --- | --- |
| Ведущий | все роли, выстрелы, проверки, план, маяк, фразу шерифа, весь протокол |
| Мирный | только свою карту |
| Шериф, дон | свою карту и свои проверки |
| Мафия и дон | всех чёрных, план отстрела, маяк, фразу, свой ночной выстрел |
| Выбывший | свою карту, действовать уже не может |
| Наблюдатель | ни одной роли, ни одной ночной тайны |
| Все после конца партии | все роли и весь протокол |

## Что реализовано из правил

- за столом от 6 до 10 игроков; при 10 состав по регламенту (6 мирных, шериф, 2 мафии, дон), при 6-9 упрощённый: чёрных двое (дон и мафия), лучший ход из двух номеров;
- места разыгрываются; игроки по очереди тянут карту из колоды, по 6 с на ход (минута на всех), не успел — карта выдаётся сама;
- комната без ведущего: таймеры идут сами, фолов нет; создатель комнаты запускает новую партию;
- договорка 60 с: план отстрела по ночам, маяк +1/+2/+3, фраза шерифа;
- речи по 60 с по кругу, первый день с №1, дальше со следующего после открывавшего;
- выставление: одна кандидатура в свою минуту, без повторов, себя можно;
- в первый день при одной кандидатуре голосования нет;
- голосование по очереди, кто не проголосовал, уходит в последнего;
- попил: 30 с на оправдание, переголосование, при повторном равенстве голосование за подъём всех;
- последняя минута ушедшим и убитым, в том числе при решающем голосовании;
- ночь: убийство только при одинаковом выстреле всех живых чёрных, иначе промах;
- проверки дона и шерифа; их шаги идут, даже если роль уже выбыла, чтобы не выдать это столу;
- лучший ход убитого в первую ночь, сгорает, если в первый день ушли двое;
- фолы: 3-й лишает ближайшей речи (при 3-4 игроках даёт 30 с), 4-й удаляет;
- удаление отменяет голосование этого или следующего дня (7.1, 7.2);
- ППК, победа красных и чёрных, ничья после трёх ночей без выбывших;
- пауза, +30 секунд, досрочный переход ведущим;
- «Распустить стол» (ведущий или создатель комнаты, с подтверждением): игра заканчивается у всех, комната закрывается;
- стол, за которым больше минуты нет живых людей (одни боты или никого), закрывается сам;
- ссылка на другой стол ведёт в него, даже если телефон помнит прежнюю игру; в прежнюю можно вернуться кнопкой;
- голос: микрофон открыт только у того, у кого слово (речь, оправдание, последняя минута), у ведущего всегда; в лобби и после партии говорят все игроки; ночью, на раздаче, в договорку и при голосовании все молчат; наблюдатели и выбывшие только слушают. Права меняет сервер через LiveKit, поэтому изменённый браузер не поможет говорить не в свою минуту. Шумоподавление Krisp из LiveKit Cloud убирает шорохи и фон; где оно недоступно, работает обычное шумоподавление браузера, в плашке голоса это видно.

## Протокол

Браузер шлёт JSON по WebSocket:

```js
{ t: 'create', nick: 'Лео' }                               // создать комнату, стать ведущим
{ t: 'join', code: 'MAF-4821', nick: 'Аня', as: 'player' }  // или as: 'spectator'
{ t: 'resume', code: 'MAF-4821', token: '...' }             // вернуться после обрыва связи
{ t: 'addBots' }                                            // ведущий: добрать стол ботами
{ t: 'start' }                                              // ведущий: начать
{ t: 'act', action: { type: 'nominate', target: 4 } }       // любой ход, см. engine/types.ts
```

Сервер отвечает `welcome` (код комнаты и токен для `resume`), `state` (лобби и `GameView` именно для этого участника) и `error`.

## Выкладка на Render

В корне лежит `render.yaml`: Render сам соберёт интерфейс (`npm install && npm run build`) и запустит сервер (`npm run serve`) на бесплатном тарифе. Версия Node задана в `.node-version`.
Голос включается тремя переменными в Environment на Render: `LIVEKIT_URL` (адрес вида `wss://...livekit.cloud`), `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`. Их выдаёт LiveKit Cloud в настройках проекта (Settings → Keys). Без них игра работает, просто без голоса.

Бесплатный сервер засыпает после 15 минут без посетителей, первый заход будит его около минуты. Итоги партий на бесплатном тарифе стираются при перезапуске.
